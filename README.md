# Chef-App
In extending the application's functionality, I implemented several key improvements to the menu management system. I enhanced the user interface by replacing the generic placeholder icons with real meal images sourced from Unsplash, restructuring the layout to display these thumbnails alongside the dish details for a more visually engaging experience. To fulfill the requirement for item management, I added a delete function to every dish card, utilizing React Native's Alert component to provide a confirmation prompt and prevent accidental deletions. Crucially, I integrated AsyncStorage into this delete function, ensuring that the updated menu list is saved locally and persists even after the application is restarted. Finally, I refactored the underlying data structure by assigning unique IDs to each dish, which guarantees that the deletion logic targets the correct item without affecting similarly named dishes.
